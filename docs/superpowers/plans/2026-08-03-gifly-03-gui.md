# gifly Plan 3 - Wails GUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A single-window Wails desktop app over the validated gifly engine: switch between Video and Images mode, pick a source, set the controls (trim/fps/size/loop/quality for video; ordered frames/frame-delay/size/loop/quality for images), convert to a GIF with a live progress readout, and preview + reveal the result.

**Architecture:** Wails v2 single window, Frameless with gifly's own title bar (the sibling pattern). Go side: `internal/app` holds the `App` struct with bound methods that wrap the engine (`internal/gifjob`, `internal/probe`, `internal/ffmpeg`) - file dialogs, probe, a conversion goroutine that emits progress events, cancel, and a preview handler. Frontend: Svelte-TS; all pure logic (formatting, validation, aspect math) lives in `frontend/src/lib` and is vitest-tested, while `.svelte` components stay thin. The engine is unchanged; this plan only adds the GUI shell and its bindings.

**Tech Stack:** Go 1.26 + Wails v2 + Svelte-TS + Vite. The bundled ffmpeg is located by the existing `internal/ffmpeg.Tools()`.

## Global Constraints

- Windows only. Go 1.26. Module `github.com/hoijun-kim/gifly`.
- cgo-free: `CGO_ENABLED=0 go build ./...` and `go test ./...` pass. `wails build` for the app itself.
- Direct Go dependencies: `github.com/wailsapp/wails/v2` is the first and only new direct dependency this plan adds (plus what Wails pulls in indirectly). No `golang.org/x/image`.
- Plain ASCII `-` only in Go/TS code and comments; never a unicode dash. No two ADJACENT single quotes in a Go doc comment (Go's doc formatter rewrites `''` to a unicode quote and gofmt fails).
- `gofmt -l .` clean; Go and TS sources LF (`.gitattributes` pins `eol=lf`).
- Commits carry NO AI co-author trailer.
- ffmpeg for manual/gated checks: `GIFLY_FFMPEG_DIR=C:\Users\hoijun\ffmpeg-dev\ffmpeg-master-latest-win64-lgpl\bin`.
- Author in wails.json: name "H.K", email "hoijun.kim00@gmail.com" (sibling convention).

```go
// Package app is the Wails binding layer: the App struct's exported methods are
// callable from the Svelte front end, and this is the only place the GUI reaches
// the engine (internal/gifjob, internal/probe, internal/ffmpeg).
package app

import "context"

// App is the Wails-bound application object.
type App struct {
	ctx context.Context
}

// NewApp constructs the App.
func NewApp() *App { return &App{} }

// Startup captures the Wails runtime context (bound in main.go's OnStartup). It
// is exported because Wails' OnStartup requires an accessible method value.
func (a *App) Startup(ctx context.Context) { a.ctx = ctx }

// Greeting is a trivial bound method proving the JS<->Go bridge; Task 2 replaces
// it with the real bindings.
func (a *App) Greeting() string { return "gifly" }
```

```go
package app

import (
	"context"

	"github.com/hoijun-kim/gifly/internal/probe"
)

// VideoInfo is what the front end shows about a picked video.
type VideoInfo struct {
	Path       string
	DurationMS int64
	Width      int
	Height     int
	FPS        float64
}

// ImageInfo is what the front end shows about one picked image.
type ImageInfo struct {
	Path   string
	Width  int
	Height int
}

// probeImageInfo reads a still's dimensions via the stdlib probe.
func probeImageInfo(path string) (ImageInfo, error) {
	f, err := probe.Image(path)
	if err != nil {
		return ImageInfo{}, err
	}
	return ImageInfo{Path: path, Width: f.Width, Height: f.Height}, nil
}

// probeVideoInfo reads a video's shape via ffprobe.
func probeVideoInfo(ffprobe, path string) (VideoInfo, error) {
	m, err := probe.Video(context.Background(), ffprobe, path)
	if err != nil {
		return VideoInfo{}, err
	}
	return VideoInfo{Path: path, DurationMS: m.DurationMS, Width: m.Width, Height: m.Height, FPS: m.FPS}, nil
}
```

### Task 8: End-to-end binding test

**Files:**
- Create: `internal/app/e2e_test.go` (build-tagged `//go:build ffmpeg`)

**Interfaces:**
- Consumes: `ConvertImages` with a real ffmpeg (the sibling e2e pattern).
- Produces: a gated test that drives `ConvertImages` end to end and asserts a real GIF is produced, so the binding layer (config mapping + engine call + result) is verified against ffmpeg, not just its pure mappers.

- [ ] **Step 1: Write the gated test**

```go
//go:build ffmpeg

package app

import (
	"context"
	"image"
	"image/color"
	"image/gif"
	"image/png"
	"os"
	"path/filepath"
	"testing"

	"github.com/hoijun-kim/gifly/internal/ffmpeg"
)

func TestConvertImagesEndToEnd(t *testing.T) {
	if _, err := ffmpeg.Tools(); err != nil {
		t.Skipf("no ffmpeg: %v", err)
	}
	dir := t.TempDir()
	mk := func(name string, w, h int, c color.RGBA) string {
		img := image.NewRGBA(image.Rect(0, 0, w, h))
		for y := 0; y < h; y++ {
			for x := 0; x < w; x++ {
				img.Set(x, y, c)
			}
		}
		p := filepath.Join(dir, name)
		f, _ := os.Create(p)
		_ = png.Encode(f, img)
		f.Close()
		return p
	}
	a := NewApp()
	a.ctx = context.Background() // no Wails runtime; events are best-effort
	out := filepath.Join(dir, "out.gif")
	req := ImagesRequest{
		Inputs:  []string{mk("a.png", 200, 120, color.RGBA{255, 0, 0, 255}), mk("b.png", 80, 200, color.RGBA{0, 0, 255, 255})},
		FrameMS: 200, Width: 240, Loop: "forever", Colors: 256, Dither: true, Out: out,
	}
	res, err := a.ConvertImages(req)
	if err != nil {
		t.Fatalf("ConvertImages = %v", err)
	}
	f, err := os.Open(res.Path)
	if err != nil {
		t.Fatal(err)
	}
	defer f.Close()
	g, err := gif.DecodeAll(f)
	if err != nil || len(g.Image) < 2 {
		t.Fatalf("output not a multi-frame GIF: %v (%d frames)", err, len(g.Image))
	}
}
```
Note: `ConvertImages` must tolerate `a.ctx` being a plain `context.Background()` with no Wails runtime - guard the `runtime.EventsEmit` progress call so it does not panic when there is no runtime (emit is best-effort; a nil-safe wrapper or a recovered call). Confirm the emit path is safe when `a.ctx` carries no Wails runtime; if Wails' EventsEmit panics without a runtime, gate the emit behind a field the test can leave unset.
